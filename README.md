# NeuroSathi

**A Low-Cost Stroke Recovery Monitoring and Rehabilitation Support Prototype**

## Problem Statement
Stroke survivors may need continued movement monitoring and rehabilitation support at home, especially when regular access to rehabilitation services is limited.

## Our Solution
NeuroSathi is a prototype concept that uses motion sensors on wristbands to compare arm movement patterns, support rehabilitation exercises, and alert caregivers when unusual movement changes are detected.

## Current Prototype Progress
- ESP32 and MPU6050 virtual circuit assembled in Wokwi.
- I2C communication configured.
- Sensor readings observed in the Serial Monitor.
- Movement-change event tested in simulation.

## Hardware Components
- ESP32
- MPU6050 motion sensor
- Wristbands (planned integration)
- Battery-powered wearable design (planned)

## Tools
